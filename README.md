# LFGN – DJ Website

Statische Website für LFGN (Music for meaningful moments), gehostet über GitHub Pages unter lfgnmusic.com.

- `index.html` – die komplette Seite (HTML + CSS + JS)
- `img/`, `portrait.jpg` – Fotos
- `logo-dark.png`, `logo-light.png` – Logo-Varianten
- `CNAME` – eigene Domain für GitHub Pages
